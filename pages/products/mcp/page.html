04 / Questions FAQ

What is MCP?

Model Context Protocol is an open standard that lets compatible AI assistants use tools and data from other software, such as Chatberry.

Can AI change things without approval?

You control which capabilities are available, and you can review results before they go live.

Which assistants work?

Any assistant that supports MCP can connect.
